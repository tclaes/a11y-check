# a11y-check.eu

> Free web accessibility checker powered by [axe-core](https://github.com/dequelabs/axe-core).

## 🚧 Status

Homepage is live with Google AdSense. The axe-core checker app is in development.

## 🗺️ Roadmap

- [x] Landing page with AdSense
- [ ] URL input → axe-core WCAG 2.1 AA audit
- [ ] Detailed issue reports with fix suggestions
- [ ] Shareable results links
- [ ] API endpoint

## 🛠️ Tech Stack

- Plain HTML/CSS/JS for the initial landing page
- [axe-core](https://github.com/dequelabs/axe-core) for accessibility analysis
- Google AdSense (`ca-pub-4950654000854684`)

## 🚀 Getting Started

```bash
git clone https://github.com/tclaes/a11y-check.git
cd a11y-check
# Open index.html in your browser — no build step needed
```
