About a11y-check

a11y-check.eu is a free, open-source web accessibility checker that helps developers, designers, and content creators identify WCAG 2.1 AA compliance issues on any publicly accessible website — no sign-up, no extensions, no cost.

The tool is built as a side project to make web accessibility testing more approachable. Too many teams skip accessibility audits because the tools are complex, expensive, or locked behind enterprise plans. a11y-check removes that barrier entirely.

How it works

When you submit a URL, our server spins up a headless Chromium browser (via Puppeteer), loads the target page, injects axe-core — Deque Systems' industry-standard accessibility engine — and runs a full automated audit. Results are returned within seconds, grouped by severity (critical, serious, moderate, minor), with HTML snippets and direct links to remediation guidance.

What is axe-core?

axe-core is an open-source accessibility testing engine developed by Deque Systems. It is trusted by Microsoft, Google, and thousands of development teams worldwide, and powers the accessibility tooling built into Chrome DevTools, the axe browser extension, and many CI/CD pipelines.

axe-core reliably detects approximately 30–40% of WCAG issues automatically — the ones that have deterministic, rule-based definitions. The remaining issues require human judgement and manual testing, which is why a11y-check also flags "needs review" items alongside confirmed violations.

What we check

  • WCAG 2.1 Level A and Level AA rules
  • Best-practice rules (colour contrast, landmark regions, skip links)
  • ARIA correctness and misuse
  • Form labelling and input identification
  • Image alternative text
  • Keyboard focus and interactive element accessibility
  • Document structure and heading hierarchy

Who built this

a11y-check is an independent open-source project. The source code is publicly available on GitHub. Contributions, bug reports, and feature suggestions are welcome via GitHub Issues.
